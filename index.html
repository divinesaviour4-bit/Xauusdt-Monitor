Setup help
  1. Create a free account at twelvedata.com and copy your API key.
  2. Open this file in Chrome or host it online. Inside the Claude preview the data request is blocked.
  3. For news, get a free key at alphavantage.co (25 requests a day). News refreshes once an hour. The dollar check uses your Twelve Data key every 30 minutes.
  4. If you enter a trade under My open trade, the app tells you when to hold and when to exit, and rings the alarm on an exit.
  5. The alarm only sounds while this page stays open and your screen is on. Tap Test alert once so the browser allows sound.
  6. Each update uses one request. The free plan has a daily limit, so use 2 or 5 minutes for long sessions.

Confidence shows how strongly the indicators agree: five technical ones (SMA trend, price vs SMA 20, MACD, RSI, momentum) plus dollar strength and news mood when available. It is not the chance the trade wins, and a 70% signal can still lose. News data is delayed and cannot see scheduled events such as Fed meetings, CPI or jobs reports, so avoid trading blind into those. Use stops and treat this as a prompt, not advice. Alerts only work while this page stays open. Gold is closed on weekends.
